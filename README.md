Manual Testing Project – E-Commerce & HIDR Website

📌 Project Overview

This repository showcases my hands-on experience in Manual Software Testing on the SauceDemo e-commerce demo website and the Himal Innovative Development & Research Pvt. Ltd. (HIDR) website.

The main objective of this project was to understand application functionality, prepare QA documentation, execute test cases, identify defects, and report bugs using industry-relevant tools and practices.

Throughout this project, I practiced the software testing life cycle (STLC), test documentation, test execution, defect reporting, and tracking.

🌐 Websites Tested

1. SauceDemo – E-Commerce Website

Website: https://www.saucedemo.com/

Focused on testing e-commerce functionality and user workflows.

Prepared test scenarios and test cases for relevant application features.

Executed positive and negative test cases.

Verified actual results against expected results.

Identified and documented issues encountered during testing.

2. HIDR – Himal Innovative Development & Research Pvt. Ltd.

Website: https://hidr.com.np/

Tested website functionality and user-facing elements.

Created test scenarios and test cases based on observable website behavior.

Executed test cases and recorded the results.

Reported identified defects with clear reproduction steps and supporting details.

🎯 Project Objectives

Understand the application's functionality from an end-user perspective.

🧪 Testing Activities Performed

Test Planning

Prepared a test plan document outlining the testing scope, objectives, approach, and test activities.

Identified the features and functionalities to be tested.

Defined the testing approach and relevant test scenarios.

Test Scenario & Test Case Design

Created test scenarios to cover important application workflows.

Designed test cases with preconditions, test steps, test data, and expected results.

Covered positive and negative scenarios where applicable.

Reviewed test cases to improve clarity, coverage, and avoid unnecessary duplication.

Test Execution

Executed test cases manually.

Compared actual results with expected results.

Recorded test execution status, including Pass and Fail.

Documented observations and collected evidence for identified issues.

Defect / Bug Reporting

Identified and documented defects encountered during test execution.

Prepared clear bug reports with:

Bug ID and summary

Environment and preconditions

Steps to reproduce

Expected result

Actual result

Severity and priority, where applicable

Screenshots or supporting evidence

Used Jira and Trello to practice defect reporting and tracking.
